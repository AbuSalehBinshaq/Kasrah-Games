# نظام Kasrah Games المتكامل - التوثيق الشامل\n\n## نظرة عامة\n\nنظام Kasrah Games المتكامل هو منصة متطورة لإدارة الألعاب والإعلانات والبيانات السحابية. يوفر النظام حلاً شاملاً للمطورين والناشرين لإدارة ألعابهم بكفاءة.\n\n## المكونات الرئيسية\n\n### 1. SDK JavaScript (v4.0.0)\n\n**الملف:** `kasrah-sdk-v4.js`\n\n#### الميزات:\n- إدارة الإعلانات (فيديو، مكافأة، بانر)\n- حفظ البيانات السحابية مع التشفير\n- تتبع الأحداث والتحليلات\n- إدارة الجلسات\n- تتبع الأخطاء\n\n#### الاستخدام الأساسي:\n\n```javascript\n// تهيئة SDK\nconst sdk = new KasrahSDK({\n  gameId: 'your-game-id',\n  apiKey: 'your-api-key',\n  debug: true,\n  encryptData: true\n});\n\n// تهيئة SDK\nawait sdk.init();\n\n// عرض إعلان فيديو\nawait sdk.showVideoAd();\n\n// عرض إعلان مكافأة\nconst completed = await sdk.showRewardedAd();\nif (completed) {\n  console.log('المستخدم أكمل الإعلان!');\n}\n\n// حفظ البيانات\nawait sdk.saveData('playerScore', { score: 1000, level: 5 });\n\n// تحميل البيانات\nconst data = await sdk.loadData('playerScore');\n\n// تتبع الأحداث\nawait sdk.trackEvent('levelComplete', { level: 5, time: 120 });\n\n// الاستماع للأحداث\nsdk.on('rewardEarned', (data) => {\n  console.log('تم كسب مكافأة:', data.reward);\n});\n\n// الحصول على إحصائيات الجلسة\nconst stats = sdk.getSessionStats();\nconsole.log('إحصائيات الجلسة:', stats);\n\n// إنهاء الجلسة\nawait sdk.endSession();\n```\n\n### 2. نظام Game ID\n\n**الغرض:** توفير معرّف فريد لكل لعبة\n\n**صيغة Game ID:**\n```\n[game-name]-[random-id]\nمثال: flappy-bird-abc123xyz789\n```\n\n**API Endpoint:**\n```\nGET/POST /api/sdk/games/manage?gameId={gameId}\n```\n\n### 3. نظام الإعلانات المتقدم\n\n**الميزات:**\n- إدارة الإعلانات (إنشاء، تحديث، حذف)\n- تتبع الانطباعات والنقرات\n- حساب الإيرادات تلقائياً\n- جدولة الإعلانات\n- تفعيل/تعطيل الإعلانات\n\n**API Endpoints:**\n```\nGET    /api/sdk/ads/manage?gameId={gameId}      - الحصول على الإعلانات\nPOST   /api/sdk/ads/manage                       - إنشاء إعلان\nPUT    /api/sdk/ads/manage                       - تحديث إعلان\nDELETE /api/sdk/ads/manage?id={adId}            - حذف إعلان\nPOST   /api/sdk/ads/track                        - تتبع الإعلان\n```\n\n### 4. نظام التحليلات المتقدم\n\n**المقاييس:**\n- إجمالي الجلسات\n- المستخدمون الفريدون\n- الإيرادات الإجمالية\n- معدل النقر (CTR)\n- متوسط مدة الجلسة\n- إجمالي الأحداث\n\n**الفترات الزمنية المدعومة:**\n- اليوم (day)\n- الأسبوع (week)\n- الشهر (month)\n- السنة (year)\n\n**API Endpoint:**\n```\nGET  /api/sdk/analytics/stats?gameId={gameId}&period={period}\nPOST /api/sdk/analytics/stats                   - حفظ إحصائيات يومية\n```\n\n### 5. نظام البيانات السحابية\n\n**الميزات:**\n- حفظ البيانات مع التشفير\n- حد أقصى 2MB لكل مستخدم\n- تتبع حجم البيانات\n- فك التشفير التلقائي\n\n**API Endpoints:**\n```\nPOST   /api/sdk/data/save-advanced              - حفظ البيانات\nGET    /api/sdk/data/save-advanced?gameId=...  - تحميل البيانات\nDELETE /api/sdk/data/save-advanced?id=...      - حذف البيانات\n```\n\n## لوحة التحكم الإدارية\n\n### الصفحات الرئيسية:\n\n#### 1. لوحة التحكم الرئيسية\n**المسار:** `/admin`\n- عرض الإحصائيات العامة\n- بطاقات سريعة لنظام SDK\n- الألعاب الحديثة\n- الإجراءات السريعة\n\n#### 2. إدارة الألعاب والـ SDK\n**المسار:** `/admin/sdk/games`\n- عرض جميع الألعاب\n- إنشاء Game ID جديد\n- إدارة API Keys\n- عرض الإحصائيات\n\n#### 3. إدارة الإعلانات\n**المسار:** `/admin/sdk/ads`\n- إنشاء إعلانات جديدة\n- تحديث الإعلانات\n- حذف الإعلانات\n- تفعيل/تعطيل الإعلانات\n- عرض الانطباعات والنقرات\n\n#### 4. التحليلات والإحصائيات\n**المسار:** `/admin/sdk/analytics`\n- رسوم بيانية متقدمة\n- إحصائيات شاملة\n- تحليل الأداء\n- مقارنة الفترات الزمنية\n\n#### 5. إدارة البيانات السحابية\n**المسار:** `/admin/sdk/data`\n- عرض بيانات اللاعبين\n- حذف البيانات\n- عرض تفاصيل البيانات\n- إحصائيات الحجم\n\n## قاعدة
