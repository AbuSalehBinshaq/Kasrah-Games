# Kasrah Games SDK v3.0.0 - Complete Summary

## 📋 نظرة عامة

**Kasrah Games SDK v3.0.0** هو SDK احترافي وقوي لدمج الألعاب مع منصة Kasrah Games. تم بناؤه من الصفر ليكون بديلاً محسّناً للإصدار السابق، مع تركيز على الأداء والموثوقية والسهولة.

## 🚀 البدء السريع

### 1. إضافة السكربت


```javascript
KasrahSDK.init({
  gameId: 'your-game-id',
```

## 🎮 أمثلة الاستخدام

### مثال 1: لعبة بسيطة

```javascript
KasrahSDK.init({ gameId: 'my-game' });

let score = 0;

async function gameLoop() {
  // اللعب
  score += 10;
  
  // عرض إعلان كل 3 طلبات
  if (score % 30 === 0) {
    await KasrahSDK.showVideoAd();
  }
  
  // حفظ البيانات
  await KasrahSDK.saveData('score', score);
  
  // تتبع الحدث
  KasrahSDK.trackEvent('scoreUpdated', { score });
}
```

### مثال 2: إدارة حسابات المستخدمين

```javascript
// تسجيل دخول
KasrahSDK.setUser({
  id: 'user-123',
  username: 'player',
  email: 'player@example.com'
});

// حفظ بيانات المستخدم
await KasrahSDK.saveData('profile', {
  username: 'player',
  level: 5,
  achievements: ['first-win', 'speedrun']
});

// تسجيل خروج
KasrahSDK.clearUser();
```

### مثال 3: تتبع الأحداث المتقدم

```javascript
// تتبع أحداث مختلفة
KasrahSDK.trackEvent('levelStart', { level: 1 });
KasrahSDK.trackEvent('levelComplete', { level: 1, time: 120 });
KasrahSDK.trackEvent('itemPurchased', { itemId: 'sword', price: 100 });
KasrahSDK.trackEvent('adWatched', { adType: 'video', reward: 100 });

// مزامنة التحليلات
await KasrahSDK.flushAnalytics();
```

## 🐛 استكشاف الأخطاء

### المشاكل الشائعة

| المشكلة | السبب | الحل |
|--------|------|------|
| SDK لا يتهيأ | gameId مفقود | أضف gameId في init config |
| الإعلانات لا تظهر | لا توجد إعلانات متاحة | تحقق من توفر الإعلانات |
| البيانات لا تُحفظ | المستخدم غير مسجل دخول | سجل دخول المستخدم أولاً |
| الأداء بطيء | حجم البيانات كبير جداً | قلل حجم البيانات |
